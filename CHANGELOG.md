# Changelog

## 0.2.0 — 2026-11-16

- Digest-pinned Ollama model evaluation with recorded runtime and generation settings.
- Manual five-task smoke and complete 60-task benchmark workflow.
- Public run exports containing responses, scores, validation, configuration and checksums.
- Smoke runs excluded from rankings and paired full-benchmark comparisons.
- Provider-aware result labels, run history and artifact downloads.
- Consolidated project documentation. Benchmark and scoring remain at v0.1.0.

## 0.1.0 — 2026-11-16

Initial research infrastructure foundation: strict task contracts, 60 original synthetic fixtures, mock provider isolation, RDKit validation, field-level scoring, experimental CRI, reproducibility checklist, cluster bootstrap and paired comparison, checkpointed runs, PostgreSQL-compatible persistence/migrations, CLI, read API, model/agent/benchmark registries, immutable snapshots, Next.js interface, tests, local deployment configuration and governance.

No real-provider rankings, external expert validation, public hosting, arena results, or DOI are claimed.
